## Day 02 — IO Package, Files

A step-by-step exploration of Java's I/O capabilities. Each exercise targets a different layer of the I/O hierarchy, from raw byte streams to character buffering to full filesystem manipulation.

| Exercise | Key concept | Description |
|----------|-------------|-------------|
| [ex00](ex00/README.md) | Byte streams | Read magic bytes from files and identify their type via a signature dictionary |
| [ex01](ex01/README.md) | Character streams | Measure cosine similarity between two text files using word-frequency vectors |
| [ex02](ex02/README.md) | Filesystem API | Interactive Unix-style file manager with `ls`, `cd`, `mv`, and `help` |
